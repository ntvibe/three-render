# Roadmap

The editor favors desktop creation, fast interaction, local project ownership, and honest rendering capabilities.

## Useful contribution areas

- A viewport-first mobile layout with temporary scene/inspector drawers.
- Action-specific Undo/Redo descriptions and clearer history navigation.
- More informative material swatches and concise render-mode explanations.
- Stronger validation of malformed project files and interrupted asset imports.
- Measured startup/bundle improvements and larger-scene profiling.
- Reproducible renderer comparison scenes with qualified results.
- Browser interaction regression coverage across supported GPUs/browsers.

Please discuss large architectural changes before implementing them. Small reproducible bug fixes, documentation, and CC0 examples are welcome directly. No item here is a delivery commitment.
