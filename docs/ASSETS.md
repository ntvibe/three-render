# Public-domain asset policy

Every bundled creative asset must be public domain or covered by a CC0-1.0 dedication. The policy applies to models, HDRs, textures, thumbnails, icons, procedural artwork, and example scenes. Open-source software licenses are handled separately.

## Bundled assets

- `public/assets/backdrop.gltf` is a newly generated neutral floor/cyclorama. Its profile is built from a line, a quarter-circle, and a wall.
- `public/assets/glass_panel.gltf` is a newly generated closed rectangular panel with a clear transmissive material.
- Catalog thumbnails and interface icons are original geometric artwork dedicated to CC0-1.0. This also covers original inline SVG artwork and CSS material swatches in the interface.
- Primitive geometry and example scene compositions generated by this project are dedicated to CC0-1.0.
- The README screenshot shows the default scene and original interface, is dedicated to CC0-1.0, and is recorded in the same manifest.
- `studio_small_09_1k.hdr` is Studio Small 09 by Sergej Majboroda / Poly Haven, provided under [Poly Haven's CC0 asset license](https://polyhaven.com/license). The bundled file's checksum was compared against the [official download](https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/studio_small_09_1k.hdr).

`public/assets/manifest.json` records source, license, and SHA-256 information. `public/assets/LICENSE` contains the official CC0 legal code. `public/assets/ATTRIBUTION.md` summarizes sources.

## Reproduce and verify

```sh
npm run assets:generate
npm run check:public
```

The generator never reads a previous model: it creates new mathematical geometry and simple geometric thumbnails. It does not download assets. The environment checksum is independently pinned by the public-release check.

For any new externally authored asset, verify the creator's actual license, include the exact source and download URL, and record its checksum. A free download, an attribution line, or a public repository alone does not establish public-domain status.

For original creative assets contributed to this project, explicitly agree to CC0-1.0 and record their provenance. Do not re-label proprietary or unknown work.

Third-party software licenses remain applicable. Refer to `THIRD_PARTY_NOTICES.md`; neither MIT-licensed code nor other software dependencies are claimed to be public domain.
