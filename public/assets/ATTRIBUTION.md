## Original generated assets

Models and catalog thumbnails are newly generated by `scripts/generate-public-assets.mjs`. Original interface icon artwork is defined in `src/icons.tsx` and `src/components/PrimitiveIcon.tsx`. These assets, other original interface artwork, procedural primitive geometry, and the two example scenes are dedicated to CC0-1.0.

The default studio lighting is bundled locally and needs no third-party runtime request. Software dependencies retain their own licenses as described in the repository's THIRD_PARTY_NOTICES.md.
